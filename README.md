# 台灣考生專屬・新制多益（TOEIC）全方位互動教材（PWA 離線版）

專為台灣多益考生整理的**免費離線互動學習 App 與完整講義**，全面採用**繁體中文**與**台灣慣用英語文法／商務專有名詞**（主詞、受詞、子句、關係子句、動名詞、不定詞、分詞構句、假設語氣、合約、履歷、品質、核銷等）。

## 手機／電腦線上開啟（啟用 GitHub Pages 後）

> **專屬網址**：`https://wuchumgyi.github.io/toeic-tw-app/`

* **iPhone（Safari）**：打開網址 → 點底部「分享」→「**加入主畫面**」→ 全螢幕離線當 App 使用。
* **Android（Chrome）**：打開網址 → 點畫面上方「**安裝 App**」（或右上角選單 → 安裝應用程式）。
* 首次載入完成後，標題旁會顯示 **`✓ 可離線`**，搭捷運無網路也能完整刷題與背單字。

---

## 核心功能一覽

1. **600 核心主題單字館（50 大職場主題 × 615 字）**：支援記憶卡翻轉、手機手指左右滑動切換、SRS 熟練度標記（不熟／模糊／已熟記）、單字與職場例句語音朗讀。
2. **鍵盤打字背單字（1,656 多益高頻詞彙｜83 章）**：致敬 Qwerty Learner 拼寫肌肉記憶模式，支援一般跟打、默寫隱藏模式與生字本複習。
3. **多益必考 12 大文法總整理**：100% 台灣文法術語、彩色 S/V/O/M 句構拆解、黃金公式、考點對照表與常見陷阱。
4. **閱讀實戰刷題（100 題）**：Part 5 句子填空（60 題，對應 12 大文法）、Part 6 段落填空（5 篇 20 題，含句子插入題）、Part 7 單篇與雙篇閱讀（5 組 20 題），每題皆附詳盡繁中詳解與自動錯題本。
5. **計時模擬測驗**：支援 **30 分鐘精簡模考（40 題）** 與 **75 分鐘全真閱讀模考（100 題）**，交卷自動估算多益閱讀量尺分數（5–495 分）並分析各文法弱點。
6. **考場多國口音切換**：內建美式（US）、英式（UK）、澳式（AU）語音朗讀切換與 0.85x–1.15x 語速調整。
